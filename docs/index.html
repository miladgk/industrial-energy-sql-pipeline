Finland's electricity grid, read in SQL.

Fingrid, Finland's grid operator, publishes hundreds of measurements and forecasts as open data, one chart at a time. This pipeline keeps 21 of them in a partitioned PostgreSQL warehouse and asks what no single chart answers: how good are the forecasts, when tomorrow will electricity be cleanest, and what unusual happened on the grid.

Real data: Fingrid Open Data, CC BY 4.0i Real measurements and forecasts. Fingrid is Finland's electricity transmission system operator. Its Open Data API publishes production, consumption, forecasts, balancing, CO2 intensity and frequency. Licence: CC BY 4.0, free to reuse with attribution. Refreshed every dayi Automated. A GitHub Action syncs the warehouse every day after Fingrid publishes the next day's forecasts at 12:00 Finnish time, reruns the SQL and redeploys this page. What was built

A Python sync from the Fingrid API into PostgreSQL (monthly partitions, idempotent upserts, a quality gate), analytics in plain SQL files and functions, a FastAPI service over the same SQL, and this static page.

Data

21 Fingrid datasets, from 1-minute frequency to hourly capacity, kept exactly as published since October 2025 and growing every day.

Questions

How far off are Fingrid's own forecasts? When is tomorrow's electricity cleanest? What unusual happened on the grid, and do independent sensors agree?

Forecasts · Real data

Forecasts, checked against reality.

Fingrid forecasts wind and consumption a day ahead and again every 15 minutes. Its site shows the forecasts and the measurements; nobody shows how far apart they were. The warehouse lines them up for every quarter-hour of the year.

How good are Fingrid's own forecasts?

Fingrid publishes its forecasts and the measured values as separate datasets, but not how far apart they were. Here every 15-minute forecast of the last 12 months is lined up with what actually happened, and the gap is scored in SQL. Two forecasts are compared: the day-ahead one, fixed at noon the day before, and the intraday one, updated every 15 minutes until the moment itself.

03
Cleanest hours · Real data

When is electricity cleanest tomorrow?

The CO2 intensity of electricity in Finland changes hour by hour with wind, demand and imports. Fingrid publishes it only as it happens; this forecasts it a day ahead, in SQL, and keeps score.

When is electricity cleanest tomorrow?

Fingrid publishes the CO2 intensity of the electricity consumed in Finland only as it happens. This page forecasts it hour by hour, from Fingrid's own day-ahead forecasts of consumption, wind and solar: the demand that wind and solar do not cover is met by imports and thermal plants, so the intensity rises with it. Shifting flexible use, such as charging a car, to the cleanest hours cuts its emissions.

Run it yourself

          
Loads the published warehouse snapshot (no Fingrid key needed), then serves and tests it. Add a free Fingrid API key to config.yaml to sync new data with make sync.

          

            
git clone https://github.com/miladgk/industrial-energy-sql-pipeline.git
cd industrial-energy-sql-pipeline
cp config_template.yaml config.yaml
pip install -r requirements.txt
docker compose up -d
make db-setup snapshot-restore quality-checks
make api        # http://localhost:8000/docs
make test
