ANOMALY DETECTION / Z-SCORE SQL

Strongest detected anomalies

The generator injects sensor-fault values (zero, or three times the sensor's normal maximum) into about 2% of readings. A SQL query computes each sensor's monthly mean and standard deviation from the normal (non-injected) readings, then flags every reading more than 3 standard deviations away (z > 3). The injected tag marks detections that match an injected value.

HOW IT WORKS / PIPELINE

From raw files to this page

SourcesSynthetic telemetry (20 facilities, 3 sensors each, 5-min) and the Fingrid Open Data API
LandingRaw CSV files in data/raw
IngestionChunked loads (5,000 rows), high-watermark incremental mode, upsert for grid data
WarehousePostgreSQL 15, readings range-partitioned by month (13 partitions)
Quality gateChecks orphans, nulls, anomaly rate and date coverage; fails the run on error
Analytics SQLz-score anomalies, rankings, rolling averages, real vs. synthetic
ServingFastAPI on Render feeds this page; Metabase for local BI
